Behavioral security for LLM-integrated smart cities

Apr 2026 · Threat model and framework

LLM security · Smart cities

When a city's AI believes false data, it acts on it, and explains it convincingly

Cities are starting to let AI language models time traffic lights, route vehicles and answer residents. Today's security checks that data arrives safely, not that the model's picture of the city is still true. This work maps where that picture breaks, and proposes how to protect it.

Report: Cognitive-Physical State Integrity: A Behavioral Security Framework for LLM-Integrated Smart City Applications (Apr 2026)

Aim

Find where AI language models in city systems can be misled into acting on a false picture of the city, and propose a defence for each weak point.

What was done

  1. Map the city in three levels. Street level (sensors and traffic lights), neighbourhood level (connected vehicles), and city level (assistants for residents and staff), each based on a real published or deployed system.
  2. Follow the data. At each level, trace data from source to action and find the step where checks on its origin, freshness or certainty are lost.
  3. Profile the attackers. Three kinds of attacker and four threats, each mapped to the standard security catalogues used by industry.
  4. Walk through real attacks. Three complete attacks, step by step, from first access to real-world harm.
  5. Propose defences. One defence for each level.

What was found

  • One root cause at every level. The city acts on what the AI model believes, and nothing checks whether that belief still matches reality. This work names the missing check Cognitive-Physical State Integrity.
  • Security checks pass, yet the model is fooled. A fake reading can be correctly signed and delivered and still mislead the model.
  • The model makes small lies bigger. It turns a local trick into confident, city-wide instructions, with a convincing explanation.
  • Deleting data is not enough. Information removed from a database can be pieced back together by the model from surrounding clues.

Why it matters

Cities are already handing traffic, routing and resident services to AI models. Firewalls and encryption check that messages arrive safely, not that the model's view of the city is true. This work shows where that gap lies and what to build to close it.

This is a threat model and a proposed framework. Building and testing the defences is the next step.
