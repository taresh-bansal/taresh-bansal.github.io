Ask My Warehouse

Aug – Sep 2026

Data engineering · LLM agents

Plain-English questions over a real data warehouse

An LLM agent that answers business questions in plain English from a real data warehouse, shows the SQL it ran, respects role-based access, and asks a human before changing any data.

Code on GitHub

How it works

  1. 1PySpark ETLCleans the raw UCI Online Retail transactions with an explicit schema. Exact duplicates are removed; stock write-offs, zero-price giveaways and accounting adjustments are quarantined in a rejects table with a reason; and automatic data-quality checks stop the pipeline if anything is off.
  2. 2PostgreSQL star schemaOne fact table at invoice-line grain, four dimensions, surrogate keys, an “Unknown customer” row and a full calendar dimension.
  3. 3MCP serverRuns as the logged-in database user and exposes tools per role: discovery, read-only SELECT, CSV export, verified metrics and approval-gated admin fixes.
  4. 4LangChain agentAnswers through the MCP tools only. Gemini first; if a call fails, the same call is retried on a local Ollama model.
  5. 5Web appFastAPI and one HTML page: chat with tables and charts, parallel conversations, and a workbook of pinned answers that refresh straight from the database.

Verified metrics

Standard business figures come from a fixed set of verified metrics assembled from tested SQL pieces, and each metric was checked against an independent query. Anything else is labeled as custom SQL and shown to the user.

Security in three layers

1. Database

PostgreSQL roles with column-level grants. Analyst logins are read-only and run under a short statement timeout.

2. Tools

The MCP server offers each role only its own tools; admin tools exist only for the admin role.

3. Human approval

Every admin change pauses for a human yes or no and is written together with its audit-log row in one transaction. The approval goes into a parameter the AI cannot set, so the AI cannot approve its own change; if no human can be asked, nothing changes.

Stack

Warehouse

AI tools
MCP Python SDK; LangChain agent with LangGraph checkpointing and interrupts
Models
Google Gemini, with a local Ollama model as fallback
App

Known limitations

  • Admin fixes to product names are overwritten when the warehouse is rebuilt; the next step is an overrides table applied by the ETL.
  • Logins are demo values, and conversations are stored as JSON files.
