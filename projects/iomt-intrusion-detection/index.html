Drift-resilient intrusion detection for IoMT

Research · Jan – Feb 2026 · BITS Pilani

Research · IoT security

An intrusion detector that adapts as medical IoT traffic shifts

Internet of Medical Things (IoMT) devices produce network traffic whose patterns change over time, so a detector trained once goes stale. This work updates the model incrementally instead of retraining it from scratch.

Paper (under review)
  • 99.94%Accuracy on WUSTL-EHMS-2020
  • +9.05Points over the best incremental baseline
  • 100%Precision
  • 0.65 sPer model-update cycle
ProblemAttack detection on medical IoT devices, where traffic shifts over time and models go stale. Retraining a batch model on every shift is slow, which leaves a window in which the detector is out of date.
ApproachAdaptive Hoeffding trees with internal node reassessment. A Hoeffding tree grows incrementally from streaming data; reassessing internal nodes re-checks earlier splits as new data arrives, so the tree can adapt when the traffic distribution drifts. Trained on the WUSTL-EHMS-2020 dataset after cleaning, with attack classes balanced using SMOTE.
Results99.94% accuracy, 9.05 points above the best incremental baseline, at 100% precision. The model updates in 0.65 s per cycle, against 41.5 s to retrain NuSVC and 199 s for Isolation Forest.

Publication

Taresh Bansal, Siva Sai, Vinay Chamola, Mohan Gurusamy. “Drift-Resilient Intrusion Detection in IoMT Networks Using Adaptive Hoeffding Trees with Internal Node Reassessment.” IEEE Internet of Things Magazine, submitted Sep 2026, under review.

Methods and data

Model
Adaptive Hoeffding trees with internal node reassessment
Data
WUSTL-EHMS-2020, cleaned; classes balanced with SMOTE
Baselines
Incremental learners; NuSVC and Isolation Forest (batch retraining)
