Drift-resilient IoMT intrusion detection

Jan – Feb 2026 · BITS Pilani

IoT security · Concept drift

An intrusion detector that adapts as medical IoT traffic shifts

Internet of Medical Things (IoMT) devices produce network traffic whose patterns change over time, so a detector trained once goes stale. This work adapts the model incrementally: each update takes 0.65 s, where retraining NuSVC (a support-vector classifier) takes 41.5 s.

Problem

Attack detection on medical IoT devices, where traffic shifts over time and models go stale. Retraining a batch model on every shift is slow, which leaves a window in which the detector is out of date.

Approach

Adaptive Hoeffding trees with internal node reassessment. A Hoeffding tree grows incrementally from streaming data; reassessing internal nodes re-checks earlier splits as new data arrives, so the tree can adapt when the traffic distribution drifts. Trained on the WUSTL-EHMS-2020 dataset after cleaning, with attack classes balanced by SMOTE oversampling.

Results

Each model update takes 0.65 s, against 41.5 s to retrain NuSVC (a support-vector classifier) and 199 s for Isolation Forest. The model reaches 99.94% accuracy, 9.05 points above the best incremental baseline, at 100% precision.

Publication

Taresh Bansal, Siva Sai, Vinay Chamola, Mohan Gurusamy. “Drift-Resilient Intrusion Detection in IoMT Networks Using Adaptive Hoeffding Trees with Internal Node Reassessment.” Under review at IEEE Internet of Things Magazine, submitted Sep 2026.
