Drift-resilient IoMT intrusion detection

Jan – Feb 2026 · BITS Pilani

IoT security · Concept drift

An intrusion detector that adapts as medical IoT traffic shifts

Internet of Medical Things (IoMT) devices produce network traffic whose patterns change over time, so a detector trained once goes stale. This work keeps the detector current by updating it incrementally as traffic arrives, instead of retraining it from scratch.

Publication entry

Problem

Retraining a batch model every time medical IoT traffic shifts is slow, and until it finishes the detector is out of date.

Approach

Adaptive Hoeffding trees with internal node reassessment. A Hoeffding tree grows incrementally from streaming data; reassessing internal nodes re-checks earlier splits as new data arrives, so the tree can adapt when the traffic distribution drifts. The model learns from the WUSTL-EHMS-2020 dataset as a stream, after cleaning, with the attack class balanced by SMOTE oversampling.

Results

On WUSTL-EHMS-2020 the model is more accurate than every incremental baseline and every batch-retrained baseline, and it raises no false alarms on the test set. Each update is faster than retraining any of the batch models, so the detector keeps pace with the traffic instead of falling behind it.

Publication

Taresh Bansal, Siva Sai, Vinay Chamola, Mohan Gurusamy. “Drift-Resilient Intrusion Detection in IoMT Networks Using Adaptive Hoeffding Trees with Internal Node Reassessment.” Under review at IEEE Internet of Things Magazine, submitted Sep 2026.

Methods and data

Model
Adaptive Hoeffding trees with internal node reassessment
Data
WUSTL-EHMS-2020, cleaned; classes balanced with SMOTE oversampling
Baselines
Incremental learners (Perceptron, Half-Space Trees, logistic regression, one-class SVM); batch models retrained from scratch (Lasso, NuSVC, Isolation Forest)
