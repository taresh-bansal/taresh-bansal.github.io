# taresh-bansal.github.io

Personal academic website of Taresh Bansal (M.E. Computer Science, BITS Pilani), served by GitHub Pages at https://taresh-bansal.github.io/.

- `index.html`: the whole site. Plain HTML and CSS with a little vanilla JavaScript (section highlighting, chart reveal, BibTeX copy). No build step.
- `assets/Taresh_Bansal_CV.pdf`: academic CV, linked from the CV section.

To update, edit `index.html` (and replace the CV PDF under the same file name), then push to the published branch.
